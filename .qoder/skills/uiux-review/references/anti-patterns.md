# 高频反模式目录

按「症状 → 用户成本 → 修法」组织。评审时先对号入座，再决定严重度。

---

## 布局与层级

**1. 工具栏等权堆叠**

- 症状：筛选、分组、排序、密度、字段、导出、全屏、新建在同一行，同形态同权重；一页 10–14 个控件。
- 成本：找不到主操作；每次都要扫描整行。
- 修法：四段式「范围｜筛选｜显示｜操作」；次要项进「更多」；置灰项放进菜单内禁用。

**2. 首屏多层控件**

- 症状：视图切换一行、搜索筛选一行、状态列头一行，内容被压到折叠线以下。
- 成本：打开页面先看控件，后看数据。
- 修法：合并搜索与筛选；计数移入列头；只保留一条工具栏。

**3. 说明文字常驻正文**

- 症状：副标题写操作指引，卡片内写口径，图例旁写键盘操作；关键说明被截断。
- 成本：信息密度失衡；真正的层级说明反而丢失。
- 修法：副标题只留定位/面包屑；规则进 `?` 或帮助抽屉；说明最多一行。

**4. 对齐锯齿**

- 症状：卡片标题被手柄/箭头缩进，正文贴内边距；左右卡顶边差 2px；数字列左对齐。
- 成本：看起来「不专业」，扫读成本增加。
- 修法：统一卡内左基线；同网格顶边；数字右对齐 + `tabular-nums`。

**5. 列头与分组行撞色**

- 症状：表头与分组带同用 `--surface-sunken`，组行像第二个表头；hover 与静止同色。
- 成本：分不清 chrome 与内容；可操作行像死区。
- 修法：表头中性灰 + 加深下边框；分组带换浅色 tint + 左侧主色条；恢复 hover 差异。

**6. 卡片右缘裁切**

- 症状：最右列卡片被页面右缘切掉，无横向滚动提示。
- 成本：用户以为内容缺失或页面坏了。
- 修法：容器留右内边距；横向滚动给渐隐/指示；或减少列宽。

## 主次与操作

**7. 主操作被视图选项压过**

- 症状：「按项目分组」是主色实心，真正的「新建」是白底；一屏 5 个以上主色按钮。
- 成本：主次失效，用户点错。
- 修法：每页唯一主色实心；视图选项中性；主按钮固定在标题行右端。

**8. 关键动作藏进「更多」**

- 症状：评审卡只有「通过」，「不通过」在更多里；关闭/恢复/删除藏在详情页。
- 成本：路径变长，用户不知道还有这个动作。
- 修法：当前状态的两个对立动作同时露出；低频才进更多。

**9. 危险操作紧邻编辑**

- 症状：卡片行 4 个纯图标直排，红色删除紧邻编辑。
- 成本：误点概率高。
- 修法：收进 `⋯`，危险项分隔；不可逆操作二次确认或撤销。

**10. 只读靠隐藏**

- 症状：无权限时按钮直接消失，没有说明；只读仍能点导出/分享。
- 成本：用户不知道是不能还是坏了；权限形同虚设。
- 修法：只读横幅/禁用原因；按权限禁用所有写与导出入口。

## 状态与语义

**11. 状态色语义过载**

- 症状：橙同时表示待处理、今天到期、阻塞、待测试、草稿、延期；同状态不同页不同色。
- 成本：颜色失去含义，只能逐个读文字。
- 修法：六类语义色；主状态之外用中性；收敛 `STATUS_META`。

**12. 徽标四套形态**

- 症状：实心、淡底、描边、纯彩字并存；读者要重新学习每页语法。
- 成本：状态识别变慢。
- 修法：只留「淡底深字=只读状态」「实心=当前选中」；可操作加 caret。

**13. 派生事实混入主状态**

- 症状：给需求加「开发中/已发布」；测试进度塞进工作项主状态。
- 成本：一对多关系被压平，信息丢失；筛选与拖拽语义混乱。
- 修法：主状态少而互斥；派生阶段用只读胶囊挂在主状态下。

**14. 同状态两套词表**

- 症状：列头「开发中/待测试/待合并/已发布」，chips「进行中/已完成/已取消」。
- 成本：用户以为是不同维度，计数无法对齐。
- 修法：全站一个词；内部状态与展示词映射到同一 `STATUS_META`。

## 反馈与数据

**15. 静默失败**

- 症状：加载失败渲染空态；重试按钮死链；保存无状态；点确定没反应。
- 成本：用户以为没数据/没生效，反复操作。
- 修法：失败给原因+重试；保存给 saving/saved；不可用给禁用原因。

**16. 假成功**

- 症状：未显式确认就写入「已确认」；批量部分失败提示全部成功。
- 成本：留下错误记录，破坏信任。
- 修法：只显式确认才写入；批量逐项结果。

**17. 统计重复与口径不明**

- 症状：同屏两处「共 187 条」；「20/27」无说明；已加载数与筛选结果关系不明。
- 成本：用户心算，容易误判。
- 修法：统计只出现一次，靠近对象；比率给最短说明或 tooltip。

**18. 0 值与空值被强调**

- 症状：逾期 0/阻塞 0 用红黄描边；KPI 三个「—」占大格；10 张空卡并列。
- 成本：强调没有信息的地方，页面像故障。
- 修法：0 值中性；空值合并；空版本折叠为一张引导卡。

**19. 可点不像可点 / 不可点像按钮**

- 症状：纯文字承担链接功能却无颜色或下划线；不可点的统计做成按钮外形；纯图标按钮没有 tooltip。
- 成本：用户反复试探，误点或漏点。
- 修法：可点给 hover/指针/caret/下划线，不可点回到中性文本；图标按钮补标签或 tooltip。

**20. 重复提交 / 提交无保护**

- 症状：保存中按钮仍可点，连点生成两条记录；超时重试重复创建；刷新后表单内容全丢。
- 成本：脏数据、重复工单、返工清理。
- 修法：提交中禁用并显示状态；写接口幂等或去重；表单失焦校验 + 本地草稿。

**21. 关键文案截断**

- 症状：状态机说明、空间名、版本名在省略号里被截掉。
- 成本：降低理解成本的文案在最复杂的页面失效。
- 修法：允许两行或 hover 展开；面包屑中间项省略、末项保留。

**22. 样式漂移**

- 症状：令牌外硬编码颜色/字号/圆角；同色值多文件重复；深色主题漏改。
- 成本：改一处漏一处，跨页不一致。
- 修法：令牌优先；用 `scan-style-drift.mjs` 定期扫；新增值先进 tokens。

## 移动端

**23. 双 FAB 叠放 / 底部遮挡**

- 症状：AI 按钮与「+」按钮垂直叠放，间距小于钮径；底部 Tab 遮住最后一张卡。
- 成本：误触；内容不可达。
- 修法：合并为一个 FAB + 展开菜单；底部留安全区。

**24. 横向溢出无提示**

- 症状：视图 Tab、状态 chips 超出屏宽，无渐隐/滚动指示。
- 成本：用户不知道右边还有内容。
- 修法：渐隐边缘、滚动指示、可横向滑动；必要时收进「更多」。

## 流程与规模

**25. 批量危险默认值**

- 症状：批量执行默认「通过/成功」，用户只勾选不选结果就提交；执行前不显示影响数量。
- 成本：一次误点写坏一批数据，且难以逐条恢复。
- 修法：默认不选结果或选最安全值；按钮带结果文案；执行前预览数量与范围。

**26. 静态数据冒充实时**

- 症状：甘特、看板、统计排完期或加载后不再随事实更新；不显示数据更新时间。
- 成本：用户按过期信息做决定，数据可信度下降。
- 修法：状态变更同步刷新；显示「更新于 …」；无法实时时明确标注快照时间。

**27. 首页只报数不驱动决策**

- 症状：首页组件只给汇总数字，看完不知道要做什么；所有角色看同一套仪表盘。
- 成本：数据到行动之间仍需用户自己翻译，首屏价值低。
- 修法：每个组件回答一个决策问题（结论 + 变化 + 下一步）；按角色给默认视图；纯统计移到报表。

**28. 看板只统计完成不显示流动**

- 症状：看板列只数各状态有多少，阻塞与卡点没有标记；站会仍需逐个点开才能发现卡住的任务。
- 成本：看不出「卡在哪一环」，看板退化成完成率图表。
- 修法：列反映真实流转，阻塞自动标红并显示负责人与停留时长；完成率移到报表。

## 使用建议

- 一次评审不要罗列全部 27 条。先找本页的 2–3 个主因，再连带同类站点。
- 反模式是线索，不是结论；必须落到具体页面与证据。
- 同一反模式在 3 个以上站点出现时，升级为「跨页结构问题」，按 P1 处理。
