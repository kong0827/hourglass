# 页面模式库

每类页面给「适用场景 → 骨架 → 必备 → 常见错误」。先选模式，再做差异；不要从空白画布自由发挥。

---

## 1. 列表页

**适用**：对象数量多、需要比较字段、需要批量操作。

**骨架**

```text
面包屑
标题 · 主操作（新建）
范围｜筛选｜显示｜操作
统计一行（共 N 项 · 已载入 M）
表头
行 × N
分页/加载更多
```

**列规则**

- 默认列 4–6 个：名称、状态、负责人、时间 + 1 个业务关键列。
- 名称列不截断或给 tooltip；数字列右对齐。
- 行操作收进行尾 `⋯`，主操作与危险操作分组。
- 全空列不渲染；整列同值列默认隐藏。

**必备状态**：首载骨架、空、筛选无结果、加载失败、只读、批量选择、加载更多。

**常见错误**：工具条 10+ 控件；统计出现两处；操作列被横向裁切；整列空白仍占宽度。

## 2. 看板

**适用**：任务有明确流转、需要发现阻塞与堆积。

**骨架**

```text
标题 · 主操作
范围｜筛选｜显示｜操作
列头（列名 + 计数）
卡片列（每列可横向滚动）
```

**卡片最少信息**：标题、状态徽标、负责人、进度或截止；阻塞项加标记与原因。

**列规则**

- 列 = 真实流转阶段，不把完成率做成列。
- 列头计数带分母解释（如「显示 20 / 共 27」）。
- 最右列不被页面右缘裁切；横向滚动给渐隐。
- 空列可折叠，不占 1/4 宽度。
- 拖拽有目标高亮与失败回滚；不可拖状态给锁定样式。

**必备状态**：空、列空、拖拽中、保存失败、只读。

**常见错误**：只统计完成数；卡片缺负责人；第 5 列被裁；拖拽后不回写。

## 3. 详情页

**适用**：单个对象的完整信息、关系与操作。

**骨架**

```text
面包屑
标题 + 状态徽标 + 主操作
关键字段摘要（2–4 项）
Tab：概览 / 子对象 / 动态 / 附件
内容区（单列或主 + 侧栏）
```

**规则**

- 首屏先给结论：状态、负责人、时间、阻塞，不把描述放最上。
- 主操作随状态变化，但每屏只有一个。
- 侧栏放关系与元信息，不放大段操作说明。
- 动态/时间线写「谁、何时、前后值」，不写「有人修改了」。
- 返回用真实历史；深链可直达。

**必备状态**：加载、404/无权限、只读、长文本、关联失败（不阻塞主体）。

**常见错误**：两个 H1；状态徽标与 meta 互相矛盾；11 个同级操作按钮。

## 4. 新建/编辑表单

**适用**：创建对象、编辑核心字段。

**容器选择**：≤3 字段弹窗；4–10 字段右侧抽屉；>10 字段或多步全页。

**骨架（全页）**

```text
面包屑
标题
[区块 1：身份与归属]
[区块 2：责任与时间]
[区块 3：关系]
[区块 4：描述与附件]
固定底栏：取消｜保存
```

**规则**

- 单列；区块标题可扫描；组内 ≤7 字段。
- 必填 `*`，选填不额外标注；依赖用显隐。
- 失焦校验格式，提交汇总必填并聚焦第一处错误。
- 单保存；自动保存要显示「已保存 · 时间」且可恢复。
- 关闭前脏检查；长表单本地草稿。
- 提交中禁用；成功后给下一步（查看详情 / 继续新建）。

**必备状态**：默认、校验错误、提交中、提交失败、只读、有未保存修改。

**常见错误**：两个保存按钮；字段类型与数据不匹配；错误只在页顶一次性列出；关闭即丢草稿。

## 5. 抽屉

**适用**：需要保留列表上下文的查看/编辑。

**骨架**

```text
头部：对象名 + 状态 + 关闭
内容：摘要 → 字段/表单 → 关联
底栏：次操作｜主操作
```

**规则**

- 宽度按内容 480–720px；桌面从右侧滑出，移动端全屏底部抽屉。
- 打开时列表滚动位置与筛选不重置。
- 抽屉内跳转不叠第二个抽屉，改为替换内容或切 Tab。
- Esc 关闭；有未保存修改时拦截。
- 焦点进入抽屉，关闭后回原触发元素。

**常见错误**：抽屉里再开命令面板；抽屉宽度撑满全屏；关闭后列表回到顶部。

## 6. 仪表盘/报表

**适用**：管理层看结果、发现偏差、下钻归因。

**骨架**

```text
标题 + 范围选择 + 时间范围
结论条（1–3 个关键变化）
KPI 行（每卡一个指标 + 口径 ?）
图表区（2 列或 2×2）
明细/下钻
```

**规则**

- 每个组件回答一个问题，不做装饰性图表。
- KPI 给分子/分母或口径 tooltip；0 值与缺失值分开表达。
- 图表轴格式统一；单位放轴标题；最大值/灰柱有图例。
- 能下钻的数字给去处；不能下钻不做可点样式。
- 显示数据更新时间；快照要标注。
- 空数据禁用导出或说明导出为空。

**必备状态**：加载、空、部分指标失败、无权限、过期数据。

**常见错误**：同页两套完成率；轴刻度混用格式；图表被裁切；所有人同一仪表盘。

## 7. 设置页

**适用**：空间/项目/个人配置。

**骨架**

```text
标题
Tab：基本 / 成员 / 通知 / 集成 / 危险区
每区块：标题 + 说明（≤1 行）+ 表单 + 保存
危险区独立，红色边框，二次确认
```

**规则**

- 每块一个保存按钮，或整页一个；不要同屏两个主保存。
- 只读字段用只读样式并说明原因，不要白底可输入样。
- 修改有脏检查；离开拦截；保存成功给时间戳。
- 危险操作与常用设置分区，必要时输入名称确认。
- 成员/权限矩阵支持批量与模板，不逐行点 42 个下拉。

**常见错误**：保存禁用但输入框像可编辑；退出空间紧邻保存；通知渠道错配无解释。

## 8. 空态 / 错误态 / 加载态

**空态**

```text
图标
标题：为什么这里是空的
一句说明（可选）
一个主操作（+ 一个次操作）
```

区分「还没有数据」与「筛选没有结果」：后者保留筛选条，给「清空筛选」。

**错误态**

```text
标题：暂时无法加载
一句原因（可自助的部分）
重试按钮
（已有数据时保留旧内容 + 顶部错误条）
```

**加载态**

- 首屏骨架与最终布局同形，不用转圈盖整页。
- 局部刷新只给局部 pending。
- 超过 300ms 才显示 loading，避免闪烁。

**常见错误**：失败渲染成空态；重试按钮是死链；空态只有「暂无数据」；永久骨架。

## 9. 登录与权限页

**骨架**

```text
品牌区（可选）
表单：账号 / 密码 / 登录
辅助：忘记密码 / 切换空间
错误：内联在字段下
```

**规则**

- 主操作唯一；错误不整页替换。
- 提交中禁用；失败给原因，不泄露账号是否存在。
- 无权限页说明「谁能给你权限」与返回路径，不给死胡同。
- 登录页可保留品牌表达，但产品内页不继承营销视觉。

**常见错误**：错误只在页顶 toast；登录按钮可连点；无权限页只有一句 403。

---

## 10. 层级树与甘特（简版）

**树**：默认展开一层；层级用缩进 + 引导线，不靠颜色；拖拽有落点高亮；超长名称截断 + tooltip；筛选后保留展开状态。

**甘特**：时间轴刻度统一；今日线可见；依赖线不遮挡文字；拖拽改期有吸附与撤销；窄屏给横向滚动与日期定位，不压缩成不可读。
