## 14. 验收清单

- [ ] 每屏一个主操作、一个 H1
- [ ] 工具条四段式，每段 ≤3 控件
- [ ] 首屏第一条数据在折叠线以上
- [ ] 空 / 加载 / 错误 / 只读 / 窄屏有设计
- [ ] 空数据与筛选无结果文案不同
- [ ] 批量默认安全，有影响预览
- [ ] 危险操作分离，有确认或撤销
- [ ] 表单单列、单保存、失焦校验、脏检查
- [ ] 颜色/字号/间距全部来自令牌
- [ ] 日期/数字/单位统一
- [ ] 键盘可走完主路径，触控 ≥44px
- [ ] 未覆盖项与假设已列出
