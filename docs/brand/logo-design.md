# 沙漏 Logo 设计方案

> 品牌名：沙漏  
> 英文名：Hourglass  
> 适用产品：东证期货内部项目管理工具  
> 设计日期：2026-11-04  
> 状态：暂定方案

---

## 1. 品牌释义

「沙漏」是时间的可视化符号，与项目管理工具的核心能力高度契合：

- **上半部**：代表计划、待办、需求池——尚未落地的任务。
- **下半部**：代表交付、完成、沉淀——已产出的价值。
- **细腰处**：代表关键路径与瓶颈，提醒团队关注流转效率。
- **沙粒流动**：象征工时计时、迭代节奏、从计划到交付的持续转化。

品牌口号（可选）：

> 让计划落地，让时间更有价值。

---

## 2. 图形设计

### 2.1 图标版

由两个上下对称的几何三角形构成沙漏轮廓：

- 外框为圆角线条，稳重且现代。
- 上半部保留三颗金沙，象征任务阶段（待处理 / 进行中 / 已完成）。
- 中间细腰处有三颗下落沙粒，象征任务持续流转。
- 下半部为堆积的沙堆，象征已完成交付的积累。

### 2.2 横版组合

图标 + 中文「沙漏」+ 英文「HOURGLASS」横向排列：

- 中文「沙漏」使用现代无衬线黑体，笔画简洁有力。
- 英文「HOURGLASS」使用大写无衬线体，字距宽松，位于中文下方。
- 图标与文字比例约为 1 : 2.5，保持视觉平衡。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 主色（深海蓝） | `#1E3A5F` | 象征稳重、信任、金融行业的专业感。 |

| 背景色（浅灰白） | `#F7F8FA` | 用于界面背景，降低视觉疲劳。 |
| 文字色（深灰） | `#101828` | 用于正文标题。 |

## 4. 标准字

- **中文**：思源黑体 / 阿里巴巴普惠体 / 系统默认无衬线黑体。
- **英文**：Inter / Montserrat / 系统默认无衬线体。
- 避免使用衬线体、书法体、卡通体。

---

## 5. 组合规范

### 5.1 最小使用尺寸

- 图标版最小边长：32px。
- 横版组合最小宽度：120px。
- 小于最小尺寸时，仅使用图标版。

### 5.2 安全空间

- 图标四周保留图标高度 1/4 的空白区域。
- 横版组合文字与图标间距不得小于图标宽度的 1/5。

### 5.3 背景适配

| 背景 | 使用版本 |
| --- | --- |
| 白色 / 浅色 | 标准色版本 |
| 深色背景 | 反白版本（图标与文字均为白色，金沙保留金色） |
| 复杂图片背景 | 仅使用图标版，并加白色描边或置于纯色容器中 |

---

## 6. 应用场景

- **登录页**：横版组合居中，下方配品牌口号。
- **顶栏**：图标版 + 中文「沙漏」左侧对齐。
- ** favicon**：仅使用图标版。
- **PPT / 汇报**：横版组合，深色或浅色背景均可。
- **系统空态 / 错误页**：图标版作为装饰元素，透明度 10%–20%。

## 7. 设计准则自检

对照通用 Logo 设计准则，当前方案评估如下：

| 准则 | 评估 | 说明 |
| --- | --- | --- |
| 简洁 | 符合 | 仅两个几何三角形 + 圆点 + 沙堆，无多余装饰。 |
| 独特 | 基本符合 | 沙漏造型通用，但通过「三颗阶段沙粒 + 下落沙粒」形成差异点。 |
| 易识别 / 易记忆 | 符合 | 一眼可辨认为沙漏，图形与品牌名直接关联。 |
| 适配多场景 | 已验证 | 提供黑白稿、反白稿、极小 favicon 预览，缩小后仍可辨认。 |
| 符合品牌定位 | 符合 | 深蓝 + 金沙配色契合金融稳重感，时间意象契合 PM 工具。 |
| 经得起时间考验 | 符合 | 扁平几何、无渐变、无流行特效，5–10 年不易过时。 |
| 色彩 / 字体克制 | 符合 | 仅一主色一辅色，中英文字体均为无衬线体。 |
| 法律 / 文化风险 | 风险低 | 「沙漏」为通用物品图形，无明显负面或宗教含义。 |
| 交付规范完整 | 已补充 | 提供 PNG 位图、SVG 矢量、黑白 / 反白 / favicon 版本。 |

## 9. 备选方向（待讨论）

若主推方案需要调整，可考虑以下方向：

1. **代码沙漏**：沙漏外框由 `{` 与 `}` 变形组成，更偏技术团队气质。
2. **上升沙漏**：下半部融入向上箭头，强调「交付 / 完成」动作。
3. **极简线条**：仅用单线轮廓表现沙漏，适合极小尺寸场景。
