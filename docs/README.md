## 辅助资料

| 目录 | 内容 |
| --- | --- |
| [`preview/`](preview/) | 设计预览稿（界面拼接与交互样稿），仅供评审，不是运行时页面 |
| [`audit/`](audit/) | 评审线框与页面优化示意图（静态 HTML） |
| [`diagrams/`](diagrams/) | 架构图、能力全景图等图表源文件与导出图 |

| [`brand/`](brand/) | 品牌素材 |
