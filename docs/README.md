## 辅助资料

| 目录 | 内容 |

| [`preview/`](preview/) | 设计预览稿（界面拼接与交互样稿），仅供评审，不是运行时页面 |
| [`audit/`](audit/) | 评审线框与页面优化示意图（静态 HTML） |
| [`diagrams/`](diagrams/) | 架构图、能力全景图等图表源文件与导出图 |
| [`images/`](images/) | 文档与博客配图 |
| [`brand/`](brand/) | 品牌素材 |
| [`archive/`](archive/) | 已归档的历史评审、实现方案与复盘，保留追溯，不再维护 |

文档中的相对链接由 `python3 tools/check-docs.py` 校验；移动文档时请同步修改引用。
