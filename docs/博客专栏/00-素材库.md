## 三、图注与排版模板

以 [03 当前正文](系列二/03-我们为什么不想再做一个大而全的平台.md)为模板：H1 → 系列行 → 封面及来源图注 → 分隔线 → 问题与短段落 → 相关正文图及图注 → 承接下一篇 → 前后链接。

1. 每篇 2–4 图，包含封面或独立博客题图；正文图跟随支撑段落，不连续堆叠。
2. 封面注明编辑来源；信息图写明「编辑示意／假设框架」，截图写明「仓库现有界面截图」，不以「这张图证明」替代来源说明。
3. 正文的假设数字、虚构人物与截图分开标注；不能将截图当作虚构案例现场，也不能据截图声称节省时长。
4. 自动计时与人工补记不能合画成统一周末／日封顶规则；接力要画出条件与人工核对。
5. 发布图应区分计划、完成、实际发布；不得画成自动部署、流水线验证、客户签名或财务结算。
6. 前两篇封面、图内文字与界面均无产品品牌；行业矩阵只作示例，不借图变相宣传。
7. [排版预览](素材/preview-layout.png)已按 01 当前文案与配图重出，作为版式示意；不代替逐篇正文、来源与发布前检查。
