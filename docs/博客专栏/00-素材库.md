## 二、视觉识别

- **配色**：藏青 `#1F3A5F`、沙金 `#C9A227`、米白 `#F7F4EC`，系列强调色仅在标签与小面积出现（行业蓝、理念绿、功能紫、场景棕、总结藏青）。
- **字体**：PingFang SC / Noto Sans SC，标题加粗，正文常规。
- **图形语言**：细网格底、白色卡片、1px 描边、轻阴影；不使用暗色底、霓虹渐变。
- **系列差异**：行业篇用「问题—成因」卡片；理念篇用原则/对照卡片；功能篇用真实截图；场景篇用路径与诊断框架；总结篇用阶段路径与能力全景。
- **封面规格**：1200 × 630（导出 2x），左上品牌/专栏标识，右侧沙漏线稿，标题两行内。
- **正文图规格**：宽 1200，高度随内容；网页展示宽度不超过正文 960，居中，配 13px 灰色图注。

## 四、排版规则

1. 封面固定放在标题与系列行之后、正文分隔线之前，不配图注。
2. 正文图放在所支撑的段落之后，前后各留一个空行；每张图配一句话图注，图注说明「这张图证明了什么」。
3. 同一篇内图片不连续堆叠；两张图之间至少保留 2–3 段文字。
4. 截图统一使用裁掉底部状态条的 `blog-*.png`，避免出现调试信息。
5. 图片来源与用途统一记录在本文件的逐篇清单中，正文不再插入 HTML 注释，保持 Markdown 干净。

## 五、生产与复现

- 封面脚本：`素材/src/build-covers.mjs` → `素材/covers/`
- 信息图脚本：`素材/src/build-infographics.mjs` → `素材/infographics/`
- 导出命令（脚本内部调用）：`node ~/.qoder/skills/diagram-craft/scripts/export-diagram.cjs <html> <png> 1200 2 root`
- HTML 源文件：`素材/src/_html/`，可修改文案后重跑，保证字体与排版一致。

## 六、关于 AI 生成图

本系列没有使用 AI 生成图，原因是：封面与信息图包含大量中文标题、功能名称与数字，AI 出图存在文字变形风险；而现有截图与架构图已能覆盖全部论点。新图全部用 HTML/CSS 绘制并由无头 Chrome 导出，文字精确、可版本管理。

如果后续需要补充「行业氛围类」插图，建议只生成不含文字的抽象场景图，并按以下提示词执行：

> 提示词 A（工具负担）：极简编辑插画，浅米白背景，深藏青与沙金配色，一张被大量便签、窗口和齿轮包围的办公桌，画面克制、留白充足，无文字、无 Logo，扁平几何风格，横向 3:2。

> 提示词 B（回归简单）：极简编辑插画，浅米白背景，深藏青与沙金配色，一条清晰的主线穿过几个简洁的方形节点，旁边是散落但被收拢的卡片，无文字、无 Logo，扁平几何风格，横向 3:2。

生成后须人工核对：不含乱码、不出现虚构界面、不与真实产品截图混用在同一段落。
