# 沙漏博客专栏 · 读者入口

> 13 篇专栏，5 个系列。围绕一个问题：项目制团队怎样把投入和交付讲清楚。
>
> 主张：减少重复，不减少追溯；让投入可解释，让交付可追溯。

## 先看一个成品

[交付说明样例](交付说明样例.md) 是一份虚构、脱敏的一页示例：承诺、实际、变更、质量、投入、证据、下周期各一段。它不是客户案例，也不能当作验收或结算凭证；用来说明本专栏所说的「交付说明」具体长什么样。

## 口径与边界

工时、完成／发布／验收、自托管／备份、规模、集成缺口、许可等统一说明集中在 [口径与边界](口径与边界.md)。各篇只解释与论点有关的部分，遇到细节以该页和产品文档为准。

本专栏是公开表达，不是产品发布承诺、试用期限或报价；使用资格与能力边界以仓库文档和实际环境为准。
