这一页的口径与实施落点

不新增表、不新增录入项，沿用现有计时、工作项与成员配置；先做空间级只读聚合，项目驾驶舱后续可复用同一接口加一张本项目趋势卡。

口径周期归属

  • 实际：按 time_log.started_at 的日期归入年 / 季；跨零点的计时整条落在开始日。
  • 预估：按工作项计划开始日（无则创建日）整条归入，不按天拆分。
  • 不补零：没有计时记录的月份 / 季度不生成柱子，避免把“没记录”误读成“没投入”。

资源维度来源

  • 成员：计时人 user_id，去重得到人力数；只计分钟 > 0 的记录，离职或不在当前名册的计时人保留。
  • 公司 / 职能：空间成员上的公司标签；同一人跨项目仍是同一公司口径。
  • 角色：项目成员角色（项目经理 / 后端 / 前端 / 产品），按项目归属，不按人硬编码。

边界不与谁相加

  • 版本：工作项可多绑版本，版本维度会重复计数，因此只做版本页单版本汇总，不进入年度投入。
  • 未结束计时：ended_at 为空不计，避免把进行中的计时算成已发生工时。
  • 预估偏差：周期归属不同，本页不展示“预估 − 实际”的偏差结论。

落点实现方式

  • 接口：GET /api/manager/investment?from=&to=&groupBy=project|member|company|role，复用现有快照加载与开发 / 测试拆分。
  • 前端：报表页新增「投入结构」页签，周期选择器 + KPI + 维度表 + 下钻，复用管理组明细表。
  • 改动量：一个只读接口 + 一个页签；无 SQL 迁移、无数据回填。
实施前确认：默认周期放「本季度」还是「本年度」；默认维度放「项目」还是「成员」；「预估」列保留还是隐藏（口径不可比）；年度是否需要与上期对比；公司 / 职能筛选先沿用报表现有筛选还是本页单独给。
