新建任务 · 归属区背景改版

只调整容器视觉层级，字段与顺序不动 · 2026-11-17

问题：归属区整块铺 --primary-soft 浅蓝底 + 主色边框 + 主色标签，在抽屉里形成第二个"提示条"焦点，和下方白色内容卡、蓝色选中模块互相争抢。改法：容器退成中性，主色只留给唯一选中项；分组靠底色/边框/间距表达，而不是靠强调色。

After 浅灰底 + 中性边框，标签回到二级灰

三种收敛方式

信息结构一致，只改容器；深浅两套令牌都随之适配
方案底色 / 边框标签颜色观感风险
现状 --primary-soft / --primary-border --primary-fg（11px 650） 像一条提示横幅，整块先于内容被看到 与选中模块同为蓝色，层级打架；深色下更闷
A · 中性分组卡
推荐		 --surface-sunken / --border --text-2 安静的一块"归属岛"，仍与正文内容卡区分 浅灰底上白色下拉框边界略弱，靠 1px 边框兜底
B · 与内容卡同款 --surface / --border --text-2 整只抽屉只剩一种卡片语言，最统一 归属区和下方内容卡之间少了层级差，扫读要慢一点
C · 去容器 透明 / 上下一根 --border --text-2 最轻，像表单里的一个普通分组段 模块 chips 悬空，窄屏下分组感依赖间距

建议采用 A：它保留了"归属与分配是一个独立区块"的语义（这点在改版里是有意设计），但把强调色收回。主色在整屏只出现在两处——标题输入框聚焦态和唯一选中的模块，视线落点更明确；深色主题下也不会出现整块发亮的蓝。若你更希望抽屉只保留一种卡片语言，选 B；若想彻底弱化这层容器，选 C。
