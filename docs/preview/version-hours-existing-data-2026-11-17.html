  • 顶层只保留「预估 / 实际」。点开进入构成页，原来占页面的「工时分布」收进浮层。
  • 预估按现有字段拆：类型 / 模块 / 负责人 / 需求 / 工作项；实际拆：成员 / 类型 / 模块 / 工作项 / 计时窗口。维度与旧「工时分布」的模块 / 负责人 / 计时窗口一致，没有减少。
  • 旧版本卡上的 6 项指标全部有着落：工作项、已完成、进行中、整体偏差、准时完成率、已排需求回到 KPI；预估、实际、剩余预估在工时卡。
  • 「工作项均耗时」只算已完成项自身的实际工时合计 ÷ 已完成项数，没有完成项显示 —；产品与原型一致，放在工时卡「实际」侧，可下钻到已完成且按实际工时排序的明细，旁边保留口径说明。
  • 概览 6 格指标只保留数值与名称，原型里的第二行小字（如「0 / 26 项」）不进产品：同样的口径在对应指标卡的口径标记与工时卡摘要里可查，避免首屏重复占高。
  • 版本说明继续在标题下展示，默认两行，超出可展开 / 收起；产品与原型同一交互，不新增字段。
  • 类型只是阶段的近似观察：需求 ≈ 设计 / 分析，任务 ≈ 开发，缺陷 ≈ 测试 / 修复。一个工作项仍可能跨多个阶段。
  • 测试窗口继续由「开测时间 / 测试结束时间」推导，只作为实际工时的筛选项；补齐这两个时间即可生效。
