沙沙漏 · UI 原型

历史版本对比
像 Git 一样左右对齐

目标：打开弹窗的第一屏就能看出「哪一段改了」，不用滚到最底部看文本差异。

现状问题

1
左右两栏是各自渲染的全文，没有行对齐，视线要来回跳。
2
差异藏在「文本差异」里，追加在弹窗最底部，要一路滚到底。
3
统一 diff 只有 ±，没有词级高亮；HTML 文档还会被抹成一行。

方案要点

1
单一滚动容器，左右行严格对齐
一个 grid 行同时承载新旧两行，滚动天然同步。
2
行级 + 词级差异
删红、增绿、改黄；行内再高亮变化的词或数字。
3
折叠未改动，差异可跳转
默认留 2 行上下文；↑↓ / n、p 跳转，右侧概览条。
4
双向选版
基准与目标都能换；当前版本也是目标之一。
5
阅读与对比分离
看原文走「阅读」，看差异走「对比」。
可行 · 后端无需新增接口
  • 两个版本正文现有接口已可取（列表、单版本）
  • Myers diff + 词级 LCS，纯前端、无第三方依赖
  • HTML 旧文档按块序列化；5000 行以上降级
新增 删除 修改
