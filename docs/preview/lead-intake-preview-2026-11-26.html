链接与治理

项目规则
链接地址/lead/{token}，token 可重置；对外不暴露空间 ID
有效期默认 90 天，可随时停用；停用后立即不可提交
频控同一手机号 5 次 / 小时；同一 IP 20 次 / 小时
查询凭据登记编号 + 手机后四位；错误时不提示具体哪项不符
附件最多 5 个、单个 20MB；仅产品侧可下载
数据可见业务侧仅见本次登记与结果，不出现项目、需求、成员数据
留痕提交、受理、接入、退回、重置链接均写操作日志

关键规则

  1. 编号不回收。线索编号 BL-YYYY-NNNN 全局唯一；接入需求后线索仍保留原编号与原文。
  2. 一需求多线索。一条需求可关联多条线索；合并时保留每条来源，统一通知提报人。
  3. 两套编号。线索不进入需求池编号体系，接入时才生成 DM 编号。
  4. 接入权限。owner / admin，或该线索的受理人，且对目标项目有写权限。
  5. 退回要说人话。必须填写业务可理解的说明，说明会原样展示给提报人。
  6. 线索不随需求消失。需求删除或迁移项目时，线索保留并记录原关联需求编号（只读）。
  7. 内部信息不外露。内部备注、优先级、评审意见、成员信息均不展示给业务侧。
