判定动作对照

强调 vs 新增

强调动作 .btn.soft

新增动作 .btn.add

  • 实线浅底只给需要被看见的主操作，例如修改判定。
  • 虚线描边只给“往区块里加东西”，例如关联、拆分、上传。
  • 两者高度都为 28px，切换样式不会让区块跳动。

视觉权重阶梯 由重到轻

  • 1主操作 .primary
  • 2强调 .soft
  • 3新增 / 上传 .add
  • 4次要 .ghost

判断口诀：独立成行、且是进入该区块的唯一入口 → 用 .add；旁边已有主按钮或属于操作簇 → 保持 .ghost。

实现

直接落到 components.css

基础 .btn 的 hover 选择器带 3 个 :not()，新增样式需同级权重才能覆盖背景与边框。

/* 区块内新增 / 上传入口：虚线描边占住一个明确点击位 */
.btn.add{background:var(--surface);border-style:dashed;border-color:var(--border-strong);color:var(--text-2);}
.btn:not(.primary):not(.danger):not(.danger-solid).add:hover{
  background:var(--primary-soft);border-style:solid;border-color:var(--primary-border);color:var(--primary-fg);
}
.btn.add [data-icon],.btn.add svg{color:var(--primary);}
.btn.add:hover [data-icon],.btn.add:hover svg{color:var(--primary-fg);}
  • 尺寸不变：仍走 .btn.sm（28px / 12.5px），只换描边与颜色，不引发布局位移。
  • 最小对比：正文 text-2 保证可读，主色只给图标；悬停才整体转主色。
  • 键盘可达：沿用全局 :focus-visible 焦点环，不依赖悬停才能辨认。
  • 深浅主题：全部使用 token，暗色下描边用 border-strong，浅底用 primary-soft，无写死颜色。
  • 上传用 label：隐藏 input[type=file] 时以 .btn.add 作可见入口，点击区域与按钮一致。
  • 不批量染色：工具条与操作簇仍保留 ghost；只有独立成行、无相邻主按钮的入口才升级，避免整页权重趋同。
