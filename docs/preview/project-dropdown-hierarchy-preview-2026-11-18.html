项目下拉层级改版 · 设计原型

项目集 → 项目 · 2026-11-18 · 覆盖筛选、表单、行内菜单与版本选择

看什么：所有项目下拉统一成「项目集 → 项目」两级。项目集只做归组与整组选择，不新增权限、版本或筛选维度； 计数仍是项目内工作项数，项目集头显示下辖合计；未分组垫底、未归类（无项目工作项）单独一行。 本页数据按线上 106/107 迁移后的结构演示，名称与计数用于展示密度。

筛选栏「项目」：项目集分组 + 整组选择

看板、列表、测试、缺陷共用同一套维度下拉。搜索同时匹配项目集与项目；勾选项目集头等于选中其下有工作项的全部项目，不新增后端筛选参数。

2统一规则

下面 12 条对所有项目下拉生效；个别位置若不适用，在覆盖清单里单独标注，而不是各自发明层级。

层级项目集 → 项目两级；分类是项目内目录，不进入任何跨项目下拉。
顺序项目集按 sort_order、再按名称；集内非容器项目在前，容器「-公共」最后；未分组永远垫底。
计数项目行 = 当前视图范围内工作项数；集头 = 下辖项目合计；未归类 = 无项目工作项数。
整组选择多选场景才提供集头复选框；只选中集内有工作项的项目，避免写入空过滤条件。
不做集筛选整组选择只是批量写项目 ID；不新增 setId 请求参数，已保存视图无需迁移。
搜索同时匹配集名与项目名；命中集名展示全集，命中项目保留父集；已选项始终可见。
折叠默认全展开，集头可折叠；搜索时强制展开；折叠状态只记本次会话，不写入保存视图。
零计数浏览时隐藏 0 工作项项目；搜索命中时展示并禁选，标注「无工作项」，避免“搜不到项目”。
空态空项目集不渲染；全部为空显示空态；搜索无匹配显示「没有匹配的项目」并提供清除搜索。
权限下拉候选范围沿用现有权限；表单里只读项目加「只读」标签且不可选，已归档项目禁选并标注。
键盘↑↓ 跨集移动，←→ 折叠/展开，Space 勾选，Esc 关闭；集头 checkbox 使用 aria-checked="mixed"。
移动端继续用原生 select + optgroup，不接管系统选择器；筛选项在手机底部面板保持同样的分组顺序。

尺寸建议：多选面板宽 326px、单选 300–360px；项目行高 30px，集头 30px 且滚动吸顶；项目文字缩进 30px（紧凑菜单 28px）；面板最高 340px（表单 310px、紧凑菜单 280px、版本选择 400px）。项目名超长单行省略，title 显示「项目集 / 项目」全路径。

3状态矩阵

逐项对照，避免实现只做了“有数据”的顺路径。

状态集头项目行底部 / 按钮
打开，无选择复选框空心，显示「N 个项目 · 合计」全部可勾选，0 计数隐藏「清空项目」禁用；按钮只显示「项目」
部分选中复选框 mixed（横线），集名不高亮选中行浅蓝底、名称主色、勾可见按钮显示「项目 N 项」或两个短名
整组选中复选框实心勾；该集全部有内容项目选中全部选中行浅蓝底正好选满一个集时显示「项目集：流程引擎 · 6 项」
搜索命中项目只保留父集，自动展开仅命中项目（含 0 计数，禁选）保留「搜索项目集或项目」输入与清除
搜索命中项目集集名高亮展示该集全部项目，含 0 计数同上
搜索无匹配不渲染空态「没有匹配的项目」提供「清除搜索」
只有未分组项目单组「未分组」，复选框可选项目行正常集头合计正常
项目已归档仍归原集名称降级 +「已归档」；表单禁选，筛选可保留旧值选中后仍可清除

项目集接口失败按项目自带 setName 兜底分组正常展示不退回平铺；无集信息才临时平铺

4需要你拍板的三处

整组选择 推荐 A

A：前端把集内项目全部勾上，继续按项目 ID 过滤；B：后端新增项目集过滤维度。

推荐 A：零后端改动，保存视图与计数口径不变

按钮文案 推荐 A

A：正好选满一个集时显示「项目集：流程引擎 · 6 项」；B：永远只显示「项目 N 项」。

推荐 A：让用户知道一次点击选中了哪一组

零计数项目 推荐 A

A：搜索命中时展示但禁选；B：完全隐藏，维持现状。

推荐 A：解决“项目明明存在却搜不到”的困惑

其余口径按本页默认执行：项目集只做归组与整组选择；版本仍按项目；分类不进入下拉；移动端保留原生选择器。
