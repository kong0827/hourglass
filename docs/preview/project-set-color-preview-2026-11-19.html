为什么选 B（色标白底）而不是集行铺淡彩：
  • 8 个集就是 8 种底色，相邻行色相来回跳，页面读起来是分段色块，不是白底表格；底色会先于名称抢走注意力。
  • 淡彩自左向右渐隐，在宽表里正好断在中段，像渲染残留；hover 也只是同色加深，低彩度集几乎看不出悬停。
  • 集色淡底会与「进行中」的蓝、阻塞/逾期的橙红抢语义；B 把颜色收紧到左条和色标图标，语义色不受干扰。
  • 层级仍由结构表达：集行有缩进、树线、16px 粗标题和 meta 行，底色不是必需的归属线索。
  • 颜色不是唯一线索：集名、文件夹图标、缩进连接线始终可见，色觉差异用户也能读。
