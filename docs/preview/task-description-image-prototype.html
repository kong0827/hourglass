任务描述支持图片上传 · 方案 B 原型

图片走独立 attachment，HTML 中保存 URL；旧纯文本数据可安全回显。

方案要点 可交互

  • 编辑器从 textarea 换成 SunEditor，保留加粗/列表/链接/图片等轻量能力。
  • 图片上传拦截到自定义逻辑，模拟 POST 到 /api/tasks/{id}/attachments?kind=description，后端返回 attachment URL。
  • HTML 保存前服务端用 jsoup 白名单清洗；前端展示再用 DOMPurify 二次过滤。
  • 旧数据无 HTML 标签时，按纯文本渲染（换行转 <br>），不破坏现有内容。
