列宽实测

—

列实测宽占列表宽

当前：只有工作项是弹性列（minmax(260px,1fr)），余量全被它吃掉，列表越宽越明显。均衡：工作项与项目两列都改弹性、按 2:1 分配（minmax(300px,2fr) / minmax(140px,1fr)），余量不再集中到第一列，两列都保留最小可读宽度。

落地改动

间距走 .mine-list 的 CSS 变量；列宽由 mine.js 的 MINE_COLS[].w 拼成 --mine-cols，两处需同步。
