# 沙漏 · UI 设计理念

> **一屏一焦点，一色一语义。**

页面层讲「不配置、不填表、不跳页」；界面层只回答一件事：**让眼睛先落在该看的地方，其余全部退到背景里。**

执行细则见 `docs/archive/ui-redesign-spec.md`，色值与尺寸以 `frontend/css/tokens.css` 为唯一真源。

---

## 一、六条原则

| 原则 | 具体做法 | 反例 |
| --- | --- | --- |
| **一屏一焦点** | 同屏只有一个实心主按钮；次级入口按「add → 实线 → link → ghost」四级降权 | 新建、导入、导出三个按钮同样醒目 |
| **一色一语义** | 品牌蓝只给主操作、选中态、焦点环；红黄绿只给状态；优先级专色只出现在标记处 | 用蓝色装饰标题、用绿色做卡片背景 |
| **层次靠明度与留白** | 用底色差、1px 细线、间距建立层级；阴影只留给浮层（抽屉 / 下拉 / 弹窗） | 卡片加投影、侧栏加渐变来"显得高级" |
| **状态先说，装饰不说** | 空、加载、错误、离线四态统一；状态用圆点、浅底徽标、细进度条表达 | 用整块大红底表示一条逾期 |
| **可读性优先于密度** | 正文 13px 起，列表行高 56 起；宁宽勿挤，长文换行，空值整段省略 | 为了多塞两列把行高压到 34px |
| **动效只解释，不表演** | 120～240ms 位移或淡入，说明"从哪来、到哪去"；尊重系统减少动画设置 | 弹跳、旋转入场、循环呼吸光 |

## 二、色彩纪律

三句话就能记住：

1. **界面 90% 是灰白的。** 背景、面板、边框、正文都取中性灰阶，层级靠深浅不靠彩度。
2. **彩色只出现在两个地方**：需要点的地方（主操作、选中），需要判断的地方（状态、优先级、风险）。
3. **一个颜色只表达一个含义。** 同一屏里红色不同时表示"危险"和"重要"，蓝色不同时表示"链接"和"信息"。

对应到令牌：

| 用途 | 令牌 | 允许出现的场景 |
| --- | --- | --- |
| 品牌蓝 | `--primary` / `--primary-soft` | 主按钮、当前选中、焦点环、进度强调 |
| 成功 | `--success` / `--success-soft` | 已完成、已发布、无风险 |
| 警告 | `--warning` / `--warning-soft` | 临期、待确认、部分完成 |
| 危险 | `--danger` / `--danger-soft` | 逾期、失败、破坏性操作 |
| 信息 | `--info` / `--info-soft` | 中性提示，不携带好坏判断 |
| 优先级 | `--p0`～`--p3` | 只出现在优先级标记本身 |

文字对比度不足时，用 `*-fg` 前景色，不加深底色；色块只做底，不做文字。

---

## 三、层次与密度

- 三层结构保持恒定：**页面底（灰）→ 内容面（白）→ 浮层（白 + 阴影）**。不加第四层。
- 分组用间距和分组标题，不用嵌套卡片；卡片不套卡片。
- 列表行高只有两档：标准 56、宽松 62。不再新增"紧凑 34"。
- 列宽按内容分配，不让单一弹性列吃掉全部余量；宽文本列设上限。
- 表格禁止合并单元格，分组靠分组行或行内重复字段。
- 移动端只保证能看，不为其增加交互分支。

## 四、状态怎么说话

| 状态 | 表达方式 | 不用 |
| --- | --- | --- |
| 默认 | 灰色文字与边框 | 默认状态也染色、加粗 |
| 生效 | 偏离默认才提色；带重置按钮的值可不染色 | 所有筛选项常亮，看不出改了什么 |
| 选中 | 浅底 + 主色文字 + 细边框 | 实心大色块 |
| 风险 | 中性词 + 颜色承载（如"需关注"配红点） | "通过 / 不通过"式评判措辞 |
| 空 | 一句当前状态 + 一个下一步动作 | 空白表格或插画占位 |
| 加载 | 保持布局骨架，局部占位 | 全屏转圈遮住内容 |

折叠摘要必须带当前值（如"更多设置 · 模块：前端"），不能只列字段名。

## 五、自检五问

评审任何一个界面前过一遍，任一条答否就回对应原则：

1. 眯眼看，第一眼落在主操作和主内容上了吗？
2. 这一屏的彩色，每一处都能说出它在表达什么状态吗？
3. 去掉所有阴影和渐变，层次还成立吗？
4. 三档字号、两档行高之外，有没有临时加的值？
5. 深色主题下，对比度和语义色是否仍然成立？

---

## 六、明确不做

- 不做渐变背景、玻璃拟态、发光边框。
- 不用 emoji 充当图标，统一 SVG。
- 不在同一屏放两个同权重主按钮。
- 不给无状态语义的元素上色。
- 不用大色块表达状态，不用颜色代替文字结论。
- 不为单个页面发明新字号、新圆角、新阴影。
