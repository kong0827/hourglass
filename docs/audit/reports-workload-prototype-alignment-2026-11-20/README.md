## 有意保留的差异（K1–K8）

| ID | 差异 | 原因 | 何时反悔 |
|---|---|---|---|
| K1 | 交付图表第 5 张「缺陷趋势」不在原型 2×2 里 | 缺陷是新版核心指标，站点独立统计；奇数卡片占整行 | 原型补第 6 张，或产品决定合并进累积流 |
| K2 | 交付图表有项目/版本/公司/角色 4 个筛选与「清除筛选」 | 站点报表接全空间数据，需要按公司/角色切片；原型只画 3 个范围控件 | 报表数据源收窄到单项目时可减 |
| K3 | 趋势与分布、流程体检的工具栏是「周期 + 说明 + 全屏」 | 分析接口按当前空间聚合，没有项目/版本参数；照搬下拉会造无效控件 | 分析接口支持按项目/版本过滤时补 |
| K4 | 完成记录是站点独有页（按月归档 + 发布态筛选） | 原型没有归档页；归档快照是产品能力 | — |
| K5 | 流程体检用单列「各列停留时长」清单，原型是 1.35fr/1fr 的条形卡 + 价值流条 | 站点把每条列停留的均值/中位/P90/在制/最久一次排开，信息等价 | 需要并列看瓶颈对比时改双卡 |
| K6 | 投入结构比原型深：AI 总结、投入趋势、成员多选、职能维度、报告导出菜单，6 KPI | 实际使用需要跨期与按人切片；原型只画 dimbar + 5 KPI + 下钻表 | — |
| K7 | 成员负载保留按周表格、分组/排序/搜索与成员工作台子页 | 名册卡与表格是两种工作方式；工作台是下钻入口 | — |
| K8 | 原型无 390 稿，移动端按全站口径（页头收起、操作回工具条） | 全站一致优先于逐像素复刻 | 出移动稿后按稿对齐 |
