在哪个项目新建用例？
1这次改了什么
  1. 全部项目仍在列表里按项目分段，但左栏不再整块收起：改成 项目 > 分组 两级导航，只做浏览与跳转。
  2. 项目段头 吸顶，滚动时不丢项目；段头直接列出该项目的主要分组，点 chip 即筛到「项目 + 分组」。
  3. 跨项目浏览时每行带 项目标识：TC 编号是项目内编号，每个项目都有 TC-001、TC-066。
  4. 写操作仍要求单项目：全部项目下「新建分组」「新建用例」先选目标项目。
2交互规则
  • 项目下拉选「全部项目」→ 左栏是两级树；选具体项目 → 回到现有分组面板（团队共享 / 指定成员 / 仅自己），行为不变。
  • 点项目节点：只看该项目；点分组节点：项目 + 分组；根节点「全部项目」或范围 chip 的 × 退回。
  • 左栏搜索会保留命中的项目节点；空项目不占位；分组计数可重叠，不做相加。
  • 段头 chip 与左栏节点是同一范围，选中态同步；「进入项目 →」等于切到单项目模式。
3边界与未做
  • 不做跨项目合并分组：同名「回归 / 冒烟」很常见，合并后无法判断筛的是哪个项目。
  • 全部项目下不开放拖拽归类、改可见范围、改名删除；这些都先进入项目。
  • 目录仍是项目内单归属结构，全部项目下继续收在单项目；移动端左栏默认收起。
  • 原型数据为演示样例，计数与接口沿用现有口径，不是真实数据。
