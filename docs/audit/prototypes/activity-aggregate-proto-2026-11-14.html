说明

数据来源、可见性与文案改动

数据来源（5 张表合并）

  • task_log — 工作项增删改移、版本范围、催办；CFG 哨兵为配置事件
  • work_activity — 项目 project、需求文档 requirement_doc
  • demand_log — 需求评审、排期、调期、取消、重开
  • dev_branch_log — 分支新建与状态流转
  • version_log — 版本创建、开始、关闭、取消、范围调整

后端统一 DTO：id / at / entityType / entityId / entityTitle / action / actionLabel / detail / actorName / projectId，按 at DESC, id DESC 分页。

可见性规则

  • 工作项事件沿用现有 project_member.access = none 过滤
  • 项目、文档、需求、分支、版本按所属项目可见性过滤；无权限项目的名称也不出现
  • 文档草稿仍按「已发布或本人负责」收敛（与文档动态流一致）
  • CFG 配置事件仅空间主 / 管理员可见，普通成员连计数都不显示
  • 删除实体后其历史事件随实体清理，聚合视图不残留

活动页文案

现在空间内的工作项操作与配置变更记录（按时间倒序，每次加载 100 条）。删除列/模块/项目这类破坏性操作也会出现在这里。
