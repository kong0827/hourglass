一个关联项，两条路

点名字开它的详情（离开本页语境）；点漏斗把本页明细联动到它（留在本页收窄）。两者共用同一份筛选状态与同一串 hash，分享出去能还原同一份明细。

  1. 1工时分布：行名与行尾漏斗都下钻。模块 / 负责人 / 阶段三个维度共用一条路径，下钻后按实际工时降序，行数恒等于该行的「N 项」。
  2. 2分支进度：chip 主体开分支抽屉，右侧漏斗只看本版本里挂这条分支的工作项——分支页看全量，这里只看本版本。
  3. 3已排需求：新增「本版本工作项」列。行名开需求详情，漏斗把明细收窄到该需求；没挂工作项时如实写「未挂工作项」，不给一个点了没反应的 0。
  4. 4工作项行内：标题下挂需求 / 分支 chip，直接开对应实体详情；行本身的点击仍然是开工作项，两者不抢。
  5. 5联动条：常驻在筛选行下方，写清当前跟着谁走。每条可单独摘掉，也可一次清除全部；分支 / 需求的名字在条上仍是详情入口。
  6. 6发布快照：工作项 / 需求编号 / 版本名都是实体入口，由全局委托统一接线——工作项与需求点开当时那一版事实对应的实体，版本名跳转到该版本的详情页。
