分组页（同一左面板第二个页签）

多归属 · 可嵌套
团队共享 · 进交付说明与发布证据
仅自己可见 · 不进证据

多归属：一条用例可进多个分组。子分组继承父组可见范围；父组计数按子树去重。只有团队共享分组进证据；证据只按顶级团队分组出一行，避免父子重复相加。

拖用例到分组＝加入（原分组保留）；拖分组到另一个分组＝改父级。同级分组上下拖动＝排序。动态分组不接受拖入（成员由规则派生）。

分组页签同样支持搜索、展开 / 折叠、按父组显示子树计数；hover 才出现新建子组 / 编辑 / 删除，减少视觉噪音。

只读成员看到的同一面板

只读：可以展开、筛选、导出；不显示新建 / 改名 / 删除按钮，也不能拖拽。目录维护需要项目写权限，删除还要负责人 / 管理员。

只读态不隐藏已有结构，只是不允许改动；查看者仍能按目录与分组理解覆盖范围。
