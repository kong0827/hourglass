「清除筛选」「重置」「一键全部已读」是 11.5px 灰字，没有图标、没有悬停态、点击区也偏小，看起来像说明文字。

当前表现11.5px 灰字，无图标、无悬停态，点击区约 16–18px 高。
预期次要操作使用 link-btn（主色 + 图标 + 悬停下划线）或 soft 按钮；点击区 ≥28px。
验证口径hover / focus 可见；键盘可到达；点击区高度 ≥28px；不再像说明文字。
修复前无 affordance11.5px 灰字
三个都是可点击操作，但外观与旁边的说明文字无法区分。
修复后可点击感link-btn + soft
第二个是键盘聚焦态；link-btn 高度 28px、有主色与图标，批量动作用 soft 按钮。
建议 统一 link-btn 与 soft 次级按钮；保留「清除筛选」「重置」的轻量语义，但补图标、悬停与 focus。 影响面：消息 / 列表 / 风险页
