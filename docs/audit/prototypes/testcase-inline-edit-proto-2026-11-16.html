方案说明 · 用例读态就地编辑

沿用工作项抽屉已验证的模型：一个抽屉、两种形态。阅读态覆盖全部字段并可点即改，编辑态只是同一字段结构换成控件；保存一律走整条 PUT，成功后留在原页签与原滚动位置。

两态对齐（本原型已按此渲染）

字段阅读态编辑态
标题点击就地改同位置输入框
优先级 / 模块事实格点开菜单 / 模块浮层同格分段 / select
关联需求 / 工作项事实格点开搜索 / 多选浮层同格按钮 + 勾选列表
前置条件 / 测试数据常显正文块，点击变输入同位置常显，不再折叠
步骤概览正文行内编辑同位置输入行
执行人 / 最近执行只读事实格同格只读（派生值不编辑）
执行历史 / 缺陷 / 变更记录页签不出现（不参与编辑）

就地编辑规则

  • 选择类选完即存；文本类失焦或 Ctrl/⌘+Enter 保存，Esc 还原。
  • 保存后留在原页签和滚动位置，不跳概览；头部左侧显示「保存中」。
  • 失败按服务器值回滚并提示（用工具条「模拟保存失败」验证），不停在没落库的新值上。
  • 改关联需求会重新继承模块并重算工作项；不匹配的工作项保存前确认移除。
  • 只读项目隐藏全部编辑入口，事实格不再显示铅笔与可点击光标。
  • 用例编号、执行人、最近执行、最近结果由执行记录派生，任何形态都不提供编辑。

批次

批次内容
P1 结构对齐元信息行收敛为「项目 · 编号 · 最近执行」；补变更记录页签；前置/测试数据常显；修徽标被长标题挤成竖排；编辑态按阅读态顺序重排。
P2 简单字段就地编辑优先级、模块、前置条件、测试数据，复用单字段保存与失败回滚。
P3 关联与步骤关联需求（级联确认）、验证工作项多选、步骤行内编辑；列表行内「编辑」改为打开详情并聚焦标题。

需要拍板

  1. 步骤放概览正文（默认展开前 5 行 + 查看全部），还是保留独立页签。
  2. 编辑态保留为「完整编辑」（新建 + 连续大改），还是只在新建时使用。
  3. 验证工作项并入事实条一格，还是保留底部 chips 区。

本原型按推荐方案渲染：步骤在概览正文、编辑态保留且与读态同构、工作项并入事实条。
