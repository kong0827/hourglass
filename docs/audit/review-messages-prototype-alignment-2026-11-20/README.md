## 有意保留的差异（K1–K7）

| ID | 差异 | 原因 | 何时反悔 |

| K3 | 类型比原型多「需求 / 成员与角色」，且只显示有数据的类型 | 站点通知类型由后端事件决定；空类型筛选只会得到空列表 | 类型收敛或需要「固定展示全部类型」时改 |
| K4 | 未读数放在页头 pill，原型在 H1 内 badge | 站点页头有统一 pill 位，位置不同但读数、语义一致 | — |
| K5 | 消息页多「截止提醒」视图（34/13 行、逾期红分组） | 逾期/临期是产品既有能力，与通知共用同一页更顺手 | 截止提醒独立成页时 |
| K6 | 无未读时「全部标为已读」不渲染 | 按钮没有可执行对象；按「永远不会有的隐藏」处理，而不是置灰占位 | 需要保留按钮位置稳定时改禁用 |
| K7 | 原型无 390 稿：消息左栏改横向卡、状态与操作落回正文头；周回顾工具条堆叠 | 全站移动口径优先于逐像素复刻 | 出移动稿后按稿对齐 |
