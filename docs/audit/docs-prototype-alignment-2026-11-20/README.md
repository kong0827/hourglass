## 结论

- 文档主页面与三个原型 section 的壳层已经**一致**：页头 H1 19/700 + 副标题 11.5、页级「从模板新建 + 新建文档」32/12.5/600/r8、工具条 48/r11、展示方式分段 30/26/r7+5、阅读双栏 300 + 10、历史版本栏 300 白卡、版本行 36 单行、对比头 45。
- 本轮统一了 10 类可见偏差：页头动态化与动作位置、模板按钮 caret、展示方式与范围快筛由胶囊改分段、阅读树与列表密度、阅读器标题 16→20、动态流文档 chip 不再整行铺满、编辑条保存圆点/可见性说明/AI 合并菜单/负责人副标题、历史页背景与版本栏、390 工具栏与历史内边距、手机打开文档后自动滚到正文。
- 文档有四种展示方式与 Univer 编辑器，原型只画「树 + 列表」与一个 markdown 风格编辑器，因此看板、动态、编辑器引擎、任意版本对比属于站点扩展；差异见「有意保留」。
