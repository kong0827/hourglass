## 保留原则

| 类型 | 处理 |
| --- | --- |
| 状态、计数、时间、范围 | 保留 |
| 权限与只读原因 | 保留，常驻一句 |
| 会改变结果的操作约束 | 保留短句，放在动作旁 |
| 指标口径 | 收进指标「?」 |
| 操作步骤、重复回显、营销语 | 删除 |
| 空态 | 标题 + 一个动作 |
