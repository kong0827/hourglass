方案 B · 显式工作流的状态机画法｜实线顺时针推进，虚线回退、撤销与关闭｜起始 待评审，结束 已发布 / 已关闭

实线：主链推进 虚线：回退 / 撤销 / 关闭 点线：已发布后另开新单 颜色只区分阶段
主链：待评审 → 已通过 → 已排期 → 开发中 → 待测试 → 测试中 → 待发布 → 已发布，每步都由人按角色推进。 回退：测试不通过、发布前回退、撤销发布记录、撤销排期、撤回评审，均写需求日志。 关闭：任意未发布状态可关闭，原因 rej / cancel / dup；恢复回关闭前状态。
环上的「另开需求」是一条新记录，不是同一条需求回流：已发布只可撤销发布记录回到待发布，不直接回到评审或关闭；后续变更另开需求或缺陷。流转的角色、必填字段与留痕表见 demand-lifecycle-v2.html。
