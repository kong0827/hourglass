刻意的取舍

不用 Redis：元数据放进程内缓存，靠 TTL 与空间版本号失效——因此定位是单实例部署，不为此引入中间件。

前后端分离但同源：前端零构建、独立发布，同源保证会话 Cookie、CSRF 与 SSE 行为不变。

部署形态

systemd 托管后端；deploy.sh 一键部署：检测改动 → 打包 → 备份数据库 → 增量 SQL → 换包 → 健康检查，支持 --dry-run / --rollback。

Nginx 只做静态托管与同源反代，不承担业务逻辑。

外部依赖

仅通知渠道可选外联：邮件、Webhook、Server酱、PushPlus；AI 模型地址由用户自配，默认禁止访问内网。

没有隐藏的中间件——看得见的每个组件都可以在自己服务器上审计。
