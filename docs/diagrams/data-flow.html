为什么不汇总：汇总表一旦存在，就和明细对不上——「补了工时但报表没变」这类问题会消耗大量解释成本。统计直读事实表，补记或作废后自动重算。
代价与边界：统计现算依赖单实例内的数据量可控——50 人以下团队实测够用，这也是定位单实例的原因之一。发布证据以 MySQL 备份为准，任务 JSON / 表格导出只是副本。
