沙漏 · 需求主状态机

主状态只有 5 个；待开工、推进中、待发布、已交付是派生展示，用虚线小胶囊挂在所属主状态下

实线：主状态推进 虚线：回退 / 关闭 点线：另开新单 虚线小胶囊：派生展示，只读
主状态：待评审 review → 已通过 pass → 已排期 plan → 已完成 done；已关闭 closed 是异常终态，不参与正常链。 派生：已排期下挂 待开工 / 推进中（由工作项真实开工信号派生）；已完成下挂 待发布 / 已交付（由生产发布记录派生，人工判定仅例外）。 完成与交付：工作项全部关闭 + 最新用例全部通过才算完成，已取消工作项不计入分母；成功生产发布才算交付。已完成 ≠ 已交付。 关闭与恢复：关闭只收未完成终止，原因 rej / cancel / dup；评审不通过的恢复回待评审；从已通过或已排期关闭的恢复回已通过，须重新排期，版本与计划日期不保留。
