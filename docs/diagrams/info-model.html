需求池
原始需求先入池评审，通过后拆成工作项；WSJF 自动打分排序，全程留痕。
通过 → 拆解为工作项
文档
项目下的方案文档，多级文档树，可派生工作项、AI 拆任务草稿。
文档 → 生成任务草稿
版本
工作项可绑定多个计划版本；版本内容、计划范围与实际发布范围三者分开统计。
工作项 ↔ 计划版本（多对多）
发布计划
一份计划可跨版本、跨项目，确定计划时间、负责人、环境与覆盖；发布日程跨项目汇总。
计划 → 预览 → 确认发布
分支
工作项可挂分支，记录负责人与目标分支，跟踪从开发、测试、合并到发布的状态。
工作项 → 挂载分支
测试
用例库与测试计划覆盖项目需求；执行失败可一键转出缺陷工作项，进入同一看板。
失败 → 转缺陷任务

工时、流转与人工确认的发布记录；工时带任务与时段，发布带环境、覆盖及计划快照，不独立验证实际部署
写入 · 拖拽、计时、补记、预览确认发布 字段 · 任务 / 时段 / 操作者 / 环境 / 计划修订 读取 · 相关视图、发布历史与周回顾
统一规则
自动计时：工作日，周末不计；个人时段默认 9–18，日上限默认 8h，均可配置
补记例外：单条 1min–24h，不按自动计时规则裁剪；工时非财务结算
计时归属：一人同一时刻只计一个任务
发布非验收：人工确认，不执行部署、不独立验 SHA、不提供客户签认
模块口径：模块合计 + 未指定 = 项目合计
看板 日历 甘特图 项目驾驶舱 报表 发布日程 发布历史 成员负载 周回顾
共享数据来源，当前统计与历史快照各有口径；任务 JSON 不含正式发布证据，证据须全库数据库 + 附件备份
