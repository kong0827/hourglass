沙漏 · 协作主链路

从想法到发布的六段协作 · 每一步都留下可回溯的事实

主线阶段虚线为留痕与支线
01需求池
收集与评审
提想法，WSJF 自动打分；四项填齐才计分。评审通过进入拆解，不通过归档，补充后可重开。
02需求文档
沉淀方案
多级文档树、全文检索与历史快照；AI 可把文档拆成任务草稿，人工确认后才落库。
03工作项
拆解与执行
任务 / 故事 / 缺陷 / 史诗；看板、日历、甘特共用一套筛选与口径，可挂模块、分支与史诗。
04版本与计划
编排发布内容
工作项可关联多个计划版本；计划可跨版本、跨项目，只描述打算怎么发。
05实际发布
确认发了什么
预览后确认，形成不可变记录；部署、重部署、回滚追加事件，完成不等于发布。
06周回顾
回看与反哺
工时与流转自动汇总为周回顾、月度清单；AI 可起周报草稿，结论回到下一轮需求与排期。
